El Pollo Loco

Controlling:

  • Arrow-Left: Character moves left.
  • Arrow-Right: Character moves right.
  • Space-bar: Character Jumps. Jump on enemy to kill them.
  • Keyboard-key D: Character throws Salsa-bottle, if collected.
  • Reload-button: reloads the game.
