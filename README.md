# 🐔 El Pollo Loco – Jump & Run Game

A browser-based 2D jump-and-run game where the player fights enemies, collects coins, and navigates through challenging levels.

---

## 📖 Description

**El Pollo Loco** is a simple 2D platformer game developed as part of a web development project.  
The player controls a character who must defeat enemies, collect items, and survive through different obstacles.

The game focuses on:
- Basic game mechanics (movement, jumping, collisions)
- Object-oriented programming in JavaScript
- Rendering animations on HTML5 Canvas

---

## 🎮 Features

- 🕹️ Classic Jump & Run gameplay  
- 🧍 Player movement (walk, jump, attack)  
- 👾 Enemy interactions  
- 💰 Collectible items (coins, bottles, etc.)  
- ❤️ Health system  
- 🎨 Sprite-based animations  
- 🔊 Sound effects  

---

## 🛠️ Tech Stack

- **JavaScript (ES6)**
- **HTML5 Canvas**
- **CSS**
- Object-Oriented Programming (OOP)
